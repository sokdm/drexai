# Retired model routes and persistent agent history

Gemini/direct Google generation is disabled at provider execution, quote admission, wallet reservation, direct request and SDK construction boundaries. Catalog discovery and user model lists filter retired Gemini/Google generation IDs, and obsolete default bindings resolve to supported non-Google adapters. YouTube API and Google authentication are preserved; those credentials are independent from Gemini.

Unstarted legacy Gemini productions are re-quoted on the server before approval cards are returned. Repair uses live catalog verification, existing pricing and compatible non-Google adapters, updates the saved draft with a compare-and-set guard, supersedes stale pending approvals and reserves no credits. Approved/in-flight legacy jobs cannot silently change their paid scope; they stop before retired provider execution and need a new approved plan.

Text fallbacks use compatible routes within the existing allowance and approved limits. Image/narration operations can automatically switch after definite 403/404/429/503 rejections to pre-quoted compatible alternatives within both the original website-credit and provider-cost ceilings. Actual execution model is stored with the output. Uncertain paid timeouts, partial output and unsupported alternatives are never blindly replayed. A model with no implemented compatible alternative cannot be promised an automatic replacement; it preserves progress and requires a new quote. Video currently has one supported non-Google adapter, Wan, so cross-model video fallback remains limited by that adapter coverage.

Chat now has an always-visible New chat and history selector. Last selected chats restore by workspace/project on reload, and every conversation is still owned and authorized server-side. New chat clears the active ID; saved conversations remain available. Server prompts retrieve relevant older saved messages and original user requirements as well as recent turns, instead of truncating to the last 1,500 characters. Context is bounded; full history stays in MongoDB, while only relevant excerpts reach the model. Conversations remain separate.

Tests use isolated MongoDB and mocked public catalogs/provider responses. No paid generation or production wallet modifications are used. Deploy web and workers together. Gemini generation keys can then be removed; retain YouTube API keys and Google OAuth credentials used for YouTube sign-in/integration.

Verification: full production build; frontend TypeScript check; 7 focused backend tests (retirement guards, bounded fallback, older memory, speech pricing, legacy draft repair with unchanged 272-credit fixture); 4 browser tests (history/new chat and mobile/desktop research chat). Catalogs/provider responses were mocked. Live paid generation was not verified.
