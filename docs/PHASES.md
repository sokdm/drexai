# Drex Phases

The original six-stage roadmap below is retained for history. The current delivery sequence documents AI Studio in [Phase 9](../PHASE9.md) and the implemented video editor/export workspace in [Phase 10](../PHASE10.md). Phase 10 does not implement publishing automation or later phases. Publishing preparation, metadata optimization and the existing authorized upload flow are covered in [Phase 11](../PHASE11.md). Customer support, feedback and notification delivery are covered in [Phase 12](../PHASE12.md). The secure business control center is documented in [Phase 13](../PHASE13.md).

## Phase 1

Project foundation, landing page, auth UI foundations, dashboard shell, responsive navigation, backend health, MongoDB connection setup, shared validation utilities, and documentation.

## Phase 2

Authentication, account verification, user profiles, protected API routes, and session handling.

## Phase 3

Credit wallet, package purchasing, Flutterwave test-mode payment verification, immutable credit ledger, transaction history, generation pricing rules, and reusable reservation/refund services.

## Phase 4

YouTube research, channel analysis, niche discovery, and content opportunity scoring.

## Phase 5

Script generation, AI image generation, image-to-video generation, voiceovers, and production orchestration.

## Phase 6

Video editor, publishing assistance, background worker, notifications, and collaboration workflows.

## Targeted corrections for Phases 5, 7, 8, 9 and 10

The current native video/audio requirements and migration behavior are specified in [NATIVE_AUDIO.md](NATIVE_AUDIO.md). These supersede earlier instructions to generate visible character speech through separate TTS or discard source video sound.
