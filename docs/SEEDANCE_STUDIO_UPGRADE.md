# Seedance Studio upgrade

Seedance 1.5 Pro is the default for new AI Studio and Product Commercial plans. Existing selected models remain available. Manual selections are recorded and are not silently replaced. Automatic selection validates each scene against the provider catalog; short scenes may require another compatible model. Dialogue requests native audio, narration uses the existing separate speech/mixing path, and silent scenes disable generated audio and avoid speech jobs. Model choice reasons are included in estimates.

Seedance website-credit quotes use the greater of its estimated cost and the verified Wan 3.0 baseline for the same duration and resolution, through the existing pricing engine. Actual Seedance usage remains separate for accounting and provider capacity. No quote can authorize an unapproved increase. Provider cost fields are removed from customer AI responses, while package dollar prices and administrator finance responses remain intact.

Video execution records submission, acceptance, polling, download and storage phases. Accepted job receipts permit recovery without another generation POST. A failed operation releases unused reservations; retry requires a fresh scoped approval. Agent redo/continue requests route to the existing regeneration tool without depending on another model-planning response. Completed assets are reused. Existing known jobs are retained for retrieval; uncertain submissions without a job ID are never automatically replayed.
