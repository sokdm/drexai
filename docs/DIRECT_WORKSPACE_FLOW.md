# Direct editor and standalone Studio

- `/dashboard/video-editor` opens a saved blank editor immediately rather than a project-selection landing page. Users can upload visuals, add clips/layers and edit before any AI Studio generation. Saved edits remain available in the editor header, and New edit opens another blank timeline. Session recovery reuses the same initialization request to avoid duplicate projects. Blank creation is an authenticated, transactional, idempotent backend action and makes no provider request.
- A manual edit has a real draft project/production association. Returning to Studio loads that same edit and its assets, without presenting the draft as completed media or a paid generation quote.
- AI Studio's Create a new video brief writes scenes through the existing durable ScriptJob worker. It persists/reconnects the job, displays actual activity, and lets users review/approve scenes within Studio. Script Builder is optional for detailed scene editing; its existing project integration remains.
- Shared chat now has one Send button and no user model selector or preliminary quote button. It requests a server quote internally, sends free messages immediately, and asks for an explicit credit confirmation if a paid model is required. Script/editor assistant buttons also say Send. Paid media generation still requires its separate approval.
- Automatic text routing checks the current MongoDB per-user and shared quotas for the number of planned calls, selects verified compatible free models while available, and offers the configured paid continuation model once unavailable. It does not bypass a provider's shared free quota by changing free model IDs. Atomic per-call admission remains enforced, so concurrent jobs or provider outages can still interrupt an operation without an unapproved paid retry.
- Script Builder and Studio scripts use this automatic routing too. Existing admin model/provider restrictions and spending controls remain active.
- Credit balance and notification bell now have separate nonshrinking space; mobile header controls are sized to fit. The embedded chat footer is bounded inside its panel to prevent overlap with live activity.

Verification is non-billable: blank editor persistence/idempotence; free quota routing; research tools and script job regressions; one-click chat on mobile/desktop; direct Studio script creation; credit/bell bounds; Script Builder controls; responsive workspace overflow; production build and TypeScript. No paid API requests or historical wallet changes are made.
